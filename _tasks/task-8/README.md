# Описание проекта

## Функциональность

Приложение пресдставляет собой сервис чатбота с UI. Пользователь общается с LLM агентом в окне чата. Все входящие промты анализируются модулем безопасности перед тем как попасть в обработку LLM. В случае если в промте обнаружена атака / нарушение комплаенс - модуль безопасности прервёт дальнейшую обработку и самостоятельно выдаст пользователю статичный нейтральный ответ.

## Архитектурная концепция

#### Обработка чата с пользователем:
1. Пользователь общается с UI через web-browser. UI реализован на фреймворке Streamlit.
2. Запросы проксируются через nginx и обрабатываются бэкендом app.
3. Бэкенд выполняет проверку авторизации, ведёт учёт операций, сохраняет данные в БД Postgres.
4. Бэкенд через RabbitMQ передаёт сырой промт в обработку цепочк генерации ответа, состоящую из ML-воркеров. После завершения обработки - получает через RabbitMQ готовый ответ для пользователя.
5. После получения ответа бэкенд так же сохраняет его в БД.
6. UI выполняет поллинг всех сообщений в чате данного пользователя с LLM и при появлении ответа - отображает его на экране. 

#### Цепочка генерации ответа:
Пайплайн генерации ответа модульный и состоит из основной LLM, а также дополнительных модулей пред- и пост-обработок, которые выполняют проверки, цензурируют фрагменты ответа или вовсе обрывают генерацию и выдают шаблонный безопасный ответ.
На данный момент пайплан следующий:
1. Предварительная проверка промта на предмет атаки (классификатор ModernBERT).
2. LLM (легковесный).

# Контекст
В рамках проекта для big tech корпорации Vega (вымышленная компания) предполагается создать систему защиты чатбота LLM. Проект является энейблепром других продуктов компании, которые невозможно запустить без надежной защиты: 
- Чатбот LLM для сотрудников
- Чатбот для клиентов - консультант на витринах продаж
- Чатбот для клиентов - консультант поддержки

В соответствии с правилами безопасности все критичные компоненты ИТ-ландшафта должны развёртываться внутри собственного корпоративного облака компании.
Запрещено допускать хранение внутрикорпоративных данных или данных клиентов во внешних SaaS сервисах.
